# Final datasets and resources

|目录|保留内容|
|---|---|
|`pretraining/`|预训练划分及字符级 token 数据|
|`couplet/`|最终单句对联训练集、反向训练集、固定测试与验证|
|`poetry_appreciation/`|完整诗文赏析最终数据、词表、切分、索引与token文件|
|`lexicon/`|最终202585词模型词库、查询库及覆盖统计|
|`resources/`|平水韵、字音和词汇检查资源，附上游许可|
|`cache/`|前向与反向冻结ChineseBERT特征缓存，可重新计算|

完整语料、数据库及缓存保留在本机并被 Git 忽略。原始下载包和早期清洗版本在 `archive/`，`raw/processed/tokenized` 为旧路径兼容入口。
